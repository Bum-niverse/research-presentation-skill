# Research Presentation Skill

A personal fork of `siril9/presentation-skill` tailored for Korean research, academic, and data-project presentations.

## Focus

- Readable Korean typography based on Pretendard
- Evidence-first slide composition
- Clear separation of claims, data, interpretation, and sources
- Reproducible deck workflows with structured planning and visual QA
- Style references for research reports, technical reviews, and data storytelling

## Repository Contents

- `SKILL.md`: main presentation workflow
- `references/`: design, planning, evidence, and rendering guidance
- `scripts/`: deck generation, rendering, inspection, and QA utilities
- `templates/`: reusable presentation templates
- `examples/` and `decks/`: generated examples and release evidence
- `plugins/`: packaged skill distribution

## Intended Use

Use this fork when creating or reviewing research presentations that require Korean-language readability, traceable evidence, and consistent visual validation.
